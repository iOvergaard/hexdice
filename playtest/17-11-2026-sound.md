# Playtest 17-11-2026: sound

**Branch:** `claude/sound-research-fe86cf`, with `main` merged in at `ff80596` (rivers with fords). Not merged into main.
**What:** synthesised sound effects on native Web Audio, built from `docs/sound-proposal.md` with the decisions of 17-11-2026: dice, capture, held, draw, knockout, your reinforcement, your-turn chime, and win/lose stings. A speaker toggle in the HUD and on the title screen.

## Gates

- `npm run check`: 111 passed, including 12 new `cuesFor` cases and 1 for parsing `?sound=`.
- `npm run sim -- --games 500`: 0 crashes, 0 illegal actions, 0 cap hits. Normal beats Easy in 86% of 1v1 games. The engine and AI are untouched; this run only confirms that.
- `E2E_PORT=5195 npm run e2e`: 53 passed, 1 skipped (that test only runs on the phone project). This includes 3 new sound tests on both desktop and phone:
  - an attack by tapping logs `dice` then its result
  - the mute toggle is remembered and shows on the title screen
  - `?sound=off` leaves the remembered setting alone
- `vite build`: 67.2 KB JS / 22.95 KB gzip. The production bundle has no cue log and no `__hexdice` hook.
