# Copy game (20-11-2026)

Jacob wants to send games he played against the Normal AI to Claude for move-by-move analysis. The engine is deterministic, so a game is its config (seed, seats, rules) plus the action log. On the live site there was no way to get that log once a game ended: `finishGame()` clears the `hexdice:save` slot, and `window.__hexdice` only exists in dev builds.

**The change.** The game-over card has a third button, Copy game (`data-testid="overlay-copy"`), after Replay (or Watch the rest) and Title. It copies `serialise(config, actions, aiRngState)` from `src/game/save.ts`, the same JSON a save holds, and a line under the buttons says "Copied. Paste it anywhere to keep or share the game." Where the browser won't write to the clipboard (no `navigator.clipboard`, or `writeText` refused), the line says "Select the text below and copy it." and the record appears in a read-only field under it, focused with all its text selected. A second press replaces the field rather than adding another.

The button is on both cards: the final one, and "You were eliminated", where the record covers the game up to your knockout. It is left out after the dev-only `__hexdice.load()`, whose action log starts mid-game; that is the same condition that hides Replay.

`restore()` is unchanged and still returns null for a finished game. The copy is for replaying and analysing, not for resuming. To replay one: `createGame(config)`, then `applyAction` over `actions` in order.

**Not mid-game.** Asked whether Copy game should also go in the game bar, Jacob chose game over only (20-11-2026).

|---|---|

| No clipboard: the field shows, has focus, all text selected; its text replays to the state on screen; a second press keeps one field; Replay, Title and Copy game stay in view; no sideways scroll | Verified: browser test on desktop and Pixel 7 with `navigator.clipboard` removed |

| Fits a 375 px phone | Verified by hand: Copy game wraps to its own centred row under Replay and Title (or Watch the rest and Title); no sideways scroll. On a Pixel 7 (412 px) all three fit one row. The existing 375 px ending test still passes |
| Copy: British English, no em dashes | Verified by reading |

## Gates

- `npm run check`: 204 passed, tsc clean.
- `npm run e2e`: 106 passed, 6 skipped (desktop and Pixel 7). A first run failed 5 phone tests because a second Playwright run of mine shared its `test-results` folder and deleted its trace files mid-run; run alone, everything passes.
- `npm run sim`: not run. Nothing in the engine or AI changed.

## Size

Seed 3 with 8 players: 132 moves to the human's knockout in round 6 came to 5,112 characters, and the whole game (233 moves) to 8,362. Fine for a clipboard or a chat message.
