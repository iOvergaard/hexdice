# Keep the save (20-11-2026)

A triage of the issue tracker found two ways a player lost a game in progress without being asked. There is no issue for either.

1. **Quit.** The game bar's Quit called `toTitle()` with no saved game, and `toTitle` deletes the save when it gets none. One tap on Quit, which sits beside sound and "?" in the phone bar, ended the game for good.
2. **Links.** Opening a `?seed=` or `?players=` link started its game through `newGame()`, which deletes the save. Opening a link someone shared cost you your own game. So did reloading a game you started from a link: it restarted from round 1.

Both reproduced in browser tests before the fix: after Quit the title had no Continue, and the link skipped the title and dealt a new game.

## The change

**Quit** goes back to the title with the save kept, so the title offers Continue game. That's the path a plain visit to the site already takes. A game you're already out of (every human knocked out, watching the AIs) still leaves nothing to continue, as the "You were eliminated" card's Title button does today.

**A link opened while a game is in progress** shows the title instead of starting. Next to Continue game there's a new button, Play linked game (`data-testid="play-link"`), and Start stays for a new random game. Your game is replaced only if you pick the link. With no game in progress, a link starts its game at once, as before.

**Why the title, and not a confirm.** The title already has the Continue game / Start pair, so one more button there needs no new component and keeps both choices one tap away. A confirm ("Replace your game?") would need a dialog the game doesn't have yet, and adds a step on top of the title. Continue game keeps the primary style, so the habitual tap resumes rather than restarts. That matters for the reload case: the link stays in the address bar, so reloading a linked game now lands on this title, and the primary button carries on.

Unchanged: Start on the title still replaces the save, and a finished game still clears it (`finishGame()`, and Title on both game-over cards).
