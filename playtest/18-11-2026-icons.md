# Playtest 18-11-2026: favicon, home-screen icons and link previews

**Branch:** `feat/icons`. No game code changed: `index.html`, `public/` and `scripts/icons.ts` only.

## What's new

- `public/favicon.svg`: the source of every icon. A flat red die showing three, on a meadow-green hex with a sand coast and an ink outline. The colours are the board's own: meadow `#a7c96a`→`#80b05b`, sand `#e9d6a0`, ink `#11152b`, and the vermilion player colour `#ff4a1c` for the die. The die is drawn front-on like the board's dice stacks, with a ground shadow under it. It has no lettering and no isometric cube.
- `npm run icons` (`scripts/icons.ts`) uses Playwright to render the SVG into:
  - `favicon.ico` (16, 32 and 48 px PNGs inside one ICO)
  - `apple-touch-icon.png` (180 px, full-bleed sea, no transparency)
  - `icon-192.png` and `icon-512.png` (a rounded sea tile)
  - `icon-maskable-512.png` (full-bleed sea, mark well inside the 80% safe circle)
  - `og-image.png` (1,200×630 link preview: the mark, the name and the tagline)
- `site.webmanifest`: name and short name "Hexdice", `display: standalone`, theme and background colour `#11152b` (the page background), relative `start_url`/`scope` and icon paths, so it also works under a sub-path.
- `index.html`: the ICO (`sizes="32x32"`) and SVG icon links, `apple-touch-icon`, manifest, `theme-color`, `apple-mobile-web-app-title`, a description, and Open Graph/Twitter title, description and image (`summary_large_image`, with absolute `https://hexdice.snebold.dk/` URLs). Vite rewrites the icon links to `./…` in `dist/`, so `base: './'` still holds.

## Why this design

I drew eight variants: amber, vermilion and ivory dice, with one die or a two-die stack, and with or without the sand coast. Then I compared them at real pixel sizes. Two-die stacks spill past the hex and turn to mush at 16 px. Amber and ivory dice sit too close to the meadow green in lightness. A larger vermilion die with white pips keeps the hex outline and shows three separate pips even at 16 px. Screens: `icons-variants.png` (all eight, 16 to 128 px) and `icons-variants-16-32px.png` (the final round, pixels magnified).

## Notes

- To change the icon, edit `public/favicon.svg` and run `npm run icons`. The PNGs and the ICO are generated files, so don't edit them by hand.
- The link-preview text uses the game's font stack. Headless Chromium on macOS falls back to Avenir Next, the same face Chrome shows in the game. A machine without that font would render the image differently, so commit the PNG and don't regenerate it in CI.
