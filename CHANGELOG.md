# Changelog

What changed in Hexdice, newest first. Players see this under What's new on the title screen.

`npm run changelog` adds new `feat`, `rules`, `fix` and `perf` commits on top. Edit the wording freely, but keep the shape: `## DD-MM-YYYY`, then `- **New:**`, `**Rules:**`, `**Fixed:**` or `**Faster:**` lines.

<!-- changelog: up to 07880c8e186ba7788d827629dcf5553e0b152fa4 -->

## 18-11-2026

- **New:** Show the last stand on the board and explain it in How to play
- **New:** Last stand for the smaller of the last two players
- **New:** How to play panel on the title screen and in game
- **New:** Favicon, home-screen icons, manifest and link previews
- **Rules:** Catch-up connection bonus on by default
- **New:** Front-line reinforcement is the default

## 17-11-2026

- **New:** A bigger, bolder board
- **New:** Seat compensation so turn order doesn't decide the game
- **Fixed:** Owner colours you can tell apart on the painted map
- **Fixed:** A continued game plays out exactly as if never reloaded
- **New:** Continue an interrupted game
- **New:** Win-chance badges on attack targets
- **New:** Synthesised sound effects with a speaker toggle
- **New:** A "big bang" when a player is knocked out
- **New:** Rivers you can only cross at a ford

Hexdice went online on 17-11-2026.
